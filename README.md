Personal portfolio for Santos Lazos, an IT Technician in San Antonio, TX (CompTIA A+, Network+, Security+, ITIL Foundation).

## Featured project: Personal Career Website

A three-page career website built by hand with HTML, CSS and JavaScript, found in [`/project`](project):

- **Resume** (`resume.html`): work history, skills and a career-highlights table
- **Cover Letter** (`cover-letter.html`): formatted letter with semantic sections
- **Career Goals** (`careergoals.html`): embedded video and audio, an ordered goals list and a contact form

**Skills used:** HTML5, CSS3 (Flexbox, ID/class/attribute selectors), JavaScript DOM updates, forms, and HTML5 audio/video.
